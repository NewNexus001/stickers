3. WORKFLOW SYNERGY — WHY IT WILL WORK
===================================================

The GitHub Actions workflow will execute these steps in sequence:

1. actions/checkout@v4
   - Checks out the repository code (including .github/workflows/build.yml)

2. actions/setup-java@v3
   - Installs OpenJDK 17 (Temurin distribution) — required for Flutter Android builds
   - Android SDK components are also installed by the Flutter action

3. subosito/flutter-action@v2
   - Installs Flutter stable channel
   - Configures Android SDK, build tools, and platform tools

4. flutter pub get
   - Resolves and downloads all dependencies from pubspec.yaml
   - Includes: flutter_localizations, shared_preferences, path_provider, url_launcher, etc.

5. flutter gen-l10n
   - Generates localization files in lib/l10n/ from ARB files
   - Regenerates app_en.arb, app_fr.arb, app_de.arb, app_ru.arb if needed
   - Required for the app's internationalization system

6. flutter build apk --release
   - Compiles the Flutter app into a release Android APK
   - Produces: build/app/outputs/flutter-apk/app-release.apk
   - Includes ProGuard/R8 minification, debug symbol stripping, and optimization

7. actions/upload-artifact@v4
   - Uploads the release APK (app-release.apk) as a GitHub Actions artifact
   - Artifact name: "Bethels-Sticker-App-APK"
   - Downloadable from the Actions run page
